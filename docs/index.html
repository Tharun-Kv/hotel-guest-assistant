🏨 AI-Powered Hotel Guest Assistant

Intelligent chat and availability system for modern hospitality

📋 Overview

A full-stack application designed to enhance the guest experience at hotels. Guests can interact with an AI-powered assistant to get instant answers about check-in times, amenities, policies, suitable rooms, and real-time availability—without waiting for the front desk.

✨ Key Features

🏨 Grounded FAQs

Answers grounded in hotel-specific knowledge about amenities, policies, and room capacity

📅 Smart Availability

Deterministic validation and booking conflict detection for accurate availability checks

🤖 Hybrid AI

Optional Gemini API for intent classification with local fallback behavior

📚 RAG System

Retrieval-augmented answers from scraped or manually approved hotel sources

⚙️ Admin Console

Operator interface at /admin for knowledge ingestion and live inventory updates

💬 Conversation Memory

Bounded session history for natural multi-turn conversations and follow-ups

🎨 Responsive UI

Modern Next.js interface with quick actions, room cards, and error handling

🔐 Security First

Pydantic contracts, CORS protection, request IDs, and structured logging

🏗️ Architecture

Browser → Next.js → FastAPI route → service / orchestrator ↓ ↓ Hotel JSON tool Availability tool ↓ ↓ Grounded facts Deterministic result ↘ ↙ Structured API response

Design Principles:

  • Routes own HTTP concerns
  • Services own business rules
  • Repositories isolate storage
  • AI interpretation is optional

🛠️ Technology Stack

Frontend Next.js 14, React 18, TypeScript, Tailwind CSS
Backend Python, FastAPI, Pydantic
AI Models Gemini API (primary), OpenAI (fallback)
Testing pytest, FastAPI TestClient
Data JSON, In-Memory Cache
Deployment GitHub Pages, Docker-ready

💡 API Endpoints

Method Endpoint Purpose
GET /health Health/version check
GET /api/hotel Public hotel knowledge data
POST /api/chat Grounded chat reply
POST /api/availability Deterministic availability lookup
POST /api/conversation Create/update conversation history
POST /api/knowledge/search Inspect retrieved source chunks
POST /api/admin/knowledge/ingest Scrape/index approved text

🚀 Quick Start

Backend Setup:

cd backend
py -3 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

Frontend Setup:

cd frontend
npm install
npm run dev

Open http://localhost:3000 to access the application.
